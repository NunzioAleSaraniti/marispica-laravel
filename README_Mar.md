# Nome Progetto

Sito web sviluppato con Laravel per la gestione di un Villaggio Turistico.

## Funzionalità
- Autenticazione utenti
- CRUD [entità]
- Ruoli (admin / user)
- Validazione dati
- Integrazione con Chatbot
- Integrazione con varie API REST

## Tecnologie
- PHP
- Laravel
- MySQL
- Blade
- Javascript
- CSS

## Installazione
1. git clone ...
2. composer install
3. cp .env.example .env
4. php artisan key:generate
5. php artisan migrate
6. php artisan serve

## Nota
Tutti i dati presenti nel progetto sono fittizi. 
Il progetto è sviluppato a scopo didattico e di portfolio.
